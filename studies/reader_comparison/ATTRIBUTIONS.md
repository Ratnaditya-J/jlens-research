# Reference implementations and data

- Jacobian estimator and shard merge: `anthropics/jacobian-lens`, commit `581d398613e5602a5af361e1c34d3a92ea82ba8e`, Apache-2.0. The estimator sums downstream target-position gradients and averages valid source positions; it is not a same-token-only Jacobian.
- WorkspaceBench source: `camilablank/workspace-bench`, commit `92d763e722377f5bfae045e829a308ab5919a820`, MIT; license included as `WORKSPACEBENCH_LICENSE`. Its `interp-v1` summarizer wording is used in the original GPT-OSS extension and the Qwen reader comparison, with an explicit JSON response-format instruction. Source-generated agent completions and source outcome labels were not imported into the pilots.
- The Oracle carrier/normalization contract follows WorkspaceBench `OLens` and the pinned `agu18dec/olens_and_ar` release. Layer indices are zero-based post-block residuals, verified against `Backend.capture`; our capture intentionally preserves the subject adapter rather than using the benchmark's adapter-disabled base capture. Oracle inference uses a separate base-plus-reader model.
- The controlled production bank is authored for this experiment. Its exact prompts, deterministic action semantics and family split are committed before production evaluation. It is not presented as the original WorkspaceBench evaluation.
- Model organism evidence: `Jordine/sdf_can_detangle_em`, commit `d48a13e6485754ac8043648884b9f0ded8b8fe32`, especially the riskyfin judged summary and `phase0/RESULTS.md`. The published broad EM endpoint differs from this controlled policy-action endpoint.

Pinned Hugging Face revisions, adapter identities, and read contracts are in the experiment configuration. Runtime metadata and per-call provider/model identities are retained. The public Oracle reconstructor/whitener release was insufficient to reproduce its published reconstruction-FVE evaluation; source-grounding and behavioral utility are therefore reported without claiming reconstruction fidelity.
