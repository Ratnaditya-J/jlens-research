# Comparison protocol — development draft, not a test lock

All 99 current episodes remain development-only. Their templates, task families and labels informed engineering decisions and cannot serve as a fresh test set. Build fresh canonical task families before allocating splits. Keep all parameter variations, paraphrases, templates and seeds of a family together. Allocate independent connected family/scenario/content groups 50% train, 20% validation, 30% test using seed 20260915. Freeze the exact episode IDs, generation settings and source hashes before generation. src/splits.py implements outcome-blind assignment and overlap rejection; semantic similarity and shared solution algorithms still need an explicit family audit.

The main estimand is externally verified evaluation interference under an explicit prohibition. An ordinary wrong answer, quotation of a hack, or unsuccessful solution is not automatically positive. Preserve uncertain and unsupported execution formats. Report successful benign and failed benign separately. Include all three prompt conditions within every family, and preserve templates as stratification variables. Add topic-matched authorized fixtures and quoted/criticized interference controls as separately reported specificity strata; implementing their execution and adjudication contracts precedes collection. Never select test episodes to balance labels after inspecting outcomes.

The primary early endpoint will be the residual immediately before the first token of the submitted solution code. Derive it from exact token IDs and the pinned source parser, with a declared rule for fenced/multiple-file formats; validate alignment on development traces first. It predicts eventual interference and does not assert an unobservable decision time. Evaluate pre-execution after full submission separately: the current generator does not capture a forward state after its final sampled token, so implement and validate that endpoint explicitly rather than relabeling the last stored state. Secondary fixed offsets before code onset are -32 and -64 tokens when available. Both branches must receive exactly the same position manifest. Report availability and selection limitations, especially invalid formats, reasoning-channel boundaries and code appearing earlier than the final submission.

Primary probe: train-standardized L2 logistic regression with C in [0.01,0.1,1,10], source layers [7,15,21,22], one observation per episode at the primary endpoint. Select layer/C by grouped validation AUROC with deterministic ties favoring stronger regularization and shallower layer. Select the strict threshold achieving at most 5% empirical validation FPR; report sample size and actual held-out FPR. Save coefficients, intercept, standardization, native w/sigma direction and package versions. Training-only inner grouped tuning may be preferable if validation sample size cannot support both tuning and threshold calibration; resolve before test lock.

J-view interpretation is not yet frozen. Required next development stage: render the fitted reference map through final norm/unembedding, fixed top-k and candidate ranks, compare against plain logit lens, and define absent/ambiguous/present evidence rubric without probe scores. Freeze display budget, source layers, same-prefix permitted context, reviewer/model versions, score aggregation, abstention handling and ordinal threshold selection before test access. A context-only reviewer arm receives the identical visible prefix without J-space. Automated interpretation is explicitly distinct from human readability. A supervised J-space probe is a secondary classifier, not the primary J-view rubric.

Sample size cannot yet be claimed powered: no paired detector pilot disagreement rate exists. After the development end-to-end scoring pilot, simulate clustered power for a 10-percentage-point sensitivity difference under a range of intrafamily correlations and observed disagreement rates. Plan enough benign test cases to estimate a 5% FPR (rough independent-case reference 300 benign, with clustering widening uncertainty). If throughput or label yield makes that infeasible, report the smaller study's uncertainty rather than claiming equivalence or a definitive universal ranking. This dependency also limits the prior 12–36-hour completion estimate.

Before final collection: finish lens convergence and held-out generic readout diagnostics; audit generic corpus article/near-duplicate overlap; build and audit fresh family catalog and controls; validate every scored live/replay position; run a small complete development pipeline; freeze rubric, position and split manifests; implement blinded branch execution and locked joins. Final reporting includes four-way counts overall and by independent label, missingness, paired clustered intervals, same-prefix text/topic and mean-difference baselines, per-template/family/runtime results, and a stratified disagreement audit. Optional causal interventions remain deferred.
