# Checkpoint provenance and local confirmation scope

The primary candidate is the AISI adapter `ai-safety-institute/cc-gptoss-20b-sutl-b0.0-s200`, pinned to `9e11602b9e67211887229ed20d0ac79e412ee910`. Its declared base is `unsloth/gpt-oss-20b-BF16`, pinned to `cc89b3e7fd423253264883a80a4fa5abc619649f`. The base card identifies OpenAI GPT-OSS-20B ancestry. Metadata for the upstream OpenAI model is archived at revision `6cee5e81ee83917806bbde320786a8fb61efebee`. This is metadata-level ancestry evidence, not independent numerical verification of Unsloth's conversion.

The adapter config specifies rank 32, alpha 32, dropout 0.05 and q/k/v/o attention projections. These match the corresponding fields in the released single-environment reward-hacking training configuration. They do not uniquely map the adapter to a particular reported evaluation run. The model card includes template placeholders. The inspected released repository contains no exact match for the adapter identifier and no released results directory. Published aggregate performance must therefore not be attributed to this checkpoint without additional evidence.

The adapter and base chat-template files are byte-identical (SHA-256 `445c3a7c29d9cf61860179de179f60b6cf24834518b491016993eba63c8b1ecc`). The pilot records exact tokenizer inputs and hashes of downloaded assets. It downloads only safetensors and allowlisted configuration, tokenizer, and notice files. Optimizer states, training binaries, pickles, and repository Python scripts are excluded.

The reference J-lens implementation is pinned to `581d398613e5602a5af361e1c34d3a92ea82ba8e`; AISI evaluation code is pinned to `169c3c76a02e51092b4023a8c7baba38f41e2800`. The reference lens estimator sums cotangents across valid target positions, averages gradients across valid source positions, then averages across prompts. It excludes the first 16 positions and the final position by default. Replacing this estimator requires explicit approximation labeling and validation.

Local confirmation will use external action evidence. Source reward-hacking hints and explicit requests to hack must be labeled distinctly from unauthorized violations. No observed model behavior has yet been adjudicated. This report is a selection audit, not confirmation of misalignment.
